Configuration Reference

Mode

mm-slider-mode="discrete"

Classic prev/next slider mode

Transition

mm-slider-transition="slide|fade"

Default: slide

Duration

mm-slider-duration="500"

Transition duration in milliseconds. Default: 500

Easing

mm-slider-ease="power2.inOut"

GSAP easing function. Default: power2.inOut

Autoplay

mm-slider-autoplay="true"

Enable auto-advance. Default: false

Autoplay Delay

mm-slider-autoplay-delay="3000"

Delay between slides in milliseconds. Default: 3000

Keyboard Navigation

mm-slider-keyboard="true"

Enable arrow key navigation. Default: true

Touch/Swipe

mm-slider-swipe="true"

Enable touch swipe navigation. Default: true

Pause on Hover

mm-slider-pauseonhover="true"

Pause autoplay on hover. Default: true
